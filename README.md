# 📝 Proyek Roro Jonggrang

Aplikasi berbasis web *task tracker* sederhana dan modern untuk mengelola *deadline* tugas-tugas sekolah, OSIS, maupun kegiatan lainnya. Dibuat murni menggunakan HTML, CSS, dan JavaScript tanpa *framework* tambahan, dengan gaya **Original Surfer** dan tema **Biru Laut Dalam (Navy)**.

## 🌟 Fitur Utama
- **Tampilan Elegan:** Desain bersih dengan warna Biru Navy formal dan font Original Surfer yang unik.
- **Kategori Khusus:** Kategori bawaan untuk 'Tugas Sekolah' dan 'OSIS Aksara Bosch'.
- **Karakter Interaktif (Pet):** Terdapat sebuah karakter mini pendamping di pojok bawah yang matanya akan selalu mengikuti arah kursor mouse. Cobalah klik karakter tersebut untuk melihat animasinya!
- **Elemen Lucu:** Menampilkan *kaomoji* dan pesan santai ketika semua tugas sudah selesai.
- **Mode Gelap (Dark Mode):** Tersedia tombol khusus untuk mengubah tema dari terang ke gelap.
- **Penyimpanan Lokal (Local Storage):** Data tidak akan hilang saat halaman di-*refresh* karena tersimpan di dalam memori peramban (*browser*).

## 🚀 Cara Menjalankan (Hosting di GitHub Pages)
1. Buat **Repository Baru** di GitHub Anda.
2. Unggah keempat file ini (`index.html`, `style.css`, `script.js`, `README.md`) ke dalam repository tersebut. **Pastikan nama file dan huruf kecil/besarnya sama persis.**
3. Buka menu **Settings** > **Pages** di repository tersebut.
4. Pada bagian *Build and deployment* (Source), pilih `Deploy from a branch`.
5. Di menu *Branch*, pilih branch `main` (atau `master`), biarkan foldernya `/ (root)`, lalu klik **Save**.
6. Tunggu 1-2 menit, GitHub akan memberikan sebuah link.
7. Bagikan link tersebut!

## 🛠️ Teknologi yang Digunakan
- HTML5
- CSS3 (Vanilla + CSS Variables untuk warna Navy, serta Custom Animation)
- Vanilla JavaScript (DOM Manipulation & Mouse Coordinate Tracking)
- Font Awesome (untuk Ikon)
- Google Fonts (Original Surfer)
