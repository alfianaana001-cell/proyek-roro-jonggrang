# 📝 Deadline Tracker

Aplikasi berbasis web sederhana untuk mengelola dan melacak *deadline* tugas-tugas sekolah, organisasi, maupun kegiatan lainnya. Dibuat murni menggunakan HTML, CSS, dan JavaScript tanpa *framework* tambahan.

## 🌟 Fitur Utama
- **Tambah Tugas Baru:** Masukkan nama tugas, kategori, dan batas waktu pengerjaan.
- **Kategori Khusus:** Kategori bawaan untuk membedakan antara 'Tugas Sekolah' dan 'OSIS Aksara Bosch' agar fokus tidak terpecah.
- **Pengurutan Otomatis:** Tugas otomatis diurutkan berdasarkan *deadline* yang paling dekat.
- **Mode Gelap (Dark Mode):** Tersedia tombol khusus untuk mengubah tema dari terang ke gelap.
- **Penyimpanan Lokal (Local Storage):** Data tidak akan hilang saat halaman di-*refresh* karena tersimpan di dalam memori peramban (*browser*).

## 🚀 Cara Menjalankan (Hosting di GitHub Pages)
Karena aplikasi ini dibuat dari sisi klien (Front-End), Anda dan teman Anda bisa langsung mempublikasikannya secara gratis!

1. Buat **Repository Baru** di GitHub Anda.
2. Unggah ketiga file ini (`index.html`, `style.css`, `script.js`) ke dalam repository tersebut.
3. Buka menu **Settings** > **Pages** di repository tersebut.
4. Pada bagian *Build and deployment* (Source), pilih `Deploy from a branch`.
5. Di menu *Branch*, pilih branch `main` (atau `master`), biarkan foldernya `/ (root)`, lalu klik **Save**.
6. Tunggu 1-2 menit, GitHub akan memberikan sebuah link (misal: `https://username.github.io/nama-repo`).
7. Bagikan link tersebut ke teman-teman agar kalian bisa mulai melacak tugas!
